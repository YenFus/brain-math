# 🧩 Theory of Mind (`theory_of_mind`)

Simulates the classic developmental psychology "Sally-Anne" false-belief task using recursive state tracking.

## How to Run
```bash
python3 theory_of_mind/sally_anne_experiment.py
```

## What It Shows
- Evaluates whether an observing agent can distinguish between its own knowledge and another agent's subjective belief.
- Demonstrates that an egocentric model fails (assuming others know what it knows), while a recursive state-tracking model correctly predicts where another character will search.
