# 💬 Language-Guided Connectome (`connectome_llm`)

Translates simple English commands into physical motor neuron currents for the simulated C. elegans worm.

## How to Run
```bash
python3 connectome_llm/connectome_llm_sim.py
```

## What It Shows
Text inputs like "sprint forward", "evade backward", or "feed" are converted into descending motor commands (AVB and AVA interneuron currents) to direct the worm's movement.
