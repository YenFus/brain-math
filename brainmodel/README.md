# 🧠 Brain Architecture (`brainmodel`)

This folder contains modular Python classes representing individual biological brain structures and their mathematical equations.

## Key Files
- `neuron.py`: Leaky integrate-and-fire neuron models and population rate equations.
- `synapse.py`: Synaptic models including NMDA receptors, LTP (potentiation), and LTD (depression).
- `neuromodulators.py`: Neurotransmitter balances (Dopamine, Serotonin, Norepinephrine, Acetylcholine, GABA, Glutamate).
- `emotion.py`: Computational models of valence, arousal, and somatic markers.
- `hippocampus.py`: Memory storage, pattern separation, and replay.
- `cerebellum.py`: Sensorimotor forward models and predictive error correction.
- `cortex.py`: Sensory, prefrontal, and motor cortical representations.
- `basal_ganglia.py`: Action selection via direct and indirect pathways.
