# 🖥️ Visualizer Dashboard

This folder contains the interactive HTML5 browser dashboard that lets you see all 13 simulations running with live visuals.

## Quick Start
Open the dashboard directly in your web browser (no local web server needed):
```bash
open visualizer/neuroai_dashboard.html
```

## Key Files
- `neuroai_dashboard.html`: The complete, zero-dependency visual interface containing 13 interactive tabs.
- `data.js`: Pre-computed simulation telemetry so the dashboard loads immediately offline.
