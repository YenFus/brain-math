# 🧬 Neuroevolution (`neuroevolution`)

Uses evolutionary algorithms to discover functional neural circuit structures without human design.

## How to Run
```bash
python3 neuroevolution/evolve_connectome.py
```

## What It Shows
Populations of random neural circuits are evaluated for rhythmic motor coordination. Over generations, the algorithm independently discovers reciprocal inhibition (alternating dorsal/ventral muscle contractions).
