# 🪞 Mirror Self-Recognition (`mirror_self_recognition`)

Demonstrates the biological "reafference principle" and efference copies used to distinguish self-movement from the external world.

## How to Run
```bash
python3 mirror_self_recognition/corollary_discharge.py
```

## What It Shows
- An agent generates an internal "efference copy" of its motor commands to predict and cancel self-induced sensory inputs.
- When facing a mirror, predicted self-movement cancels out, keeping the agent calm.
- When the efference copy is ablated or an external stranger approaches, the uncancelled movement triggers a defensive escape reflex.
