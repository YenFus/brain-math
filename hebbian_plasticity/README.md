# 🔔 Hebbian Plasticity & Conditioning (`hebbian_plasticity`)

Demonstrates classical Pavlovian associative conditioning in a biological neural circuit.

## How to Run
```bash
python3 hebbian_plasticity/pavlovian_conditioning.py
```

## What It Shows
- Pairs an initially neutral vibration tone with a noxious stimulus.
- Through 3-factor synaptic plasticity (STDP), the synapse strengthens over several trials.
- Eventually, the tone alone triggers the escape reflex without any noxious stimulus present.
