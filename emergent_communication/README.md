# 🗣️ Emergent Communication (`emergent_communication`)

A cooperative task where two agents develop an acoustic signaling system from scratch.

## How to Run
```bash
python3 emergent_communication/proto_language_sim.py
```

## What It Shows
- **Scout Agent**: Observes a target direction (North, South, East, West) and emits continuous dual-frequency sounds.
- **Harvester Agent**: Listens to the sound frequencies and selects the matching gate switch.
- Demonstrates how a structured mapping between direction and sound frequencies develops through shared cooperative rewards.
